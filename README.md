# Atlas Template Base

The official application template for the Atlas Ecosystem.

This repository provides a production-ready foundation for building Atlas applications with modern web technologies.

## Features

- Next.js (App Router)
- TypeScript
- Tailwind CSS
- ESLint
- Docker Support
- GitHub Actions
- Production-ready structure

## Intended Usage

Create new Atlas applications from this template.

Examples:

- Atlas Research
- Atlas Studio
- Atlas AI
- Atlas Cloud
- Atlas Admin
